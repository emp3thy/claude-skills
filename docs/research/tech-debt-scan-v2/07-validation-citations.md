# Validation: traceability of the numbers behind the v2 design

Validation note for tech-debt-scan v2. Written 2026-09-02. Each load-bearing number in `06-design-brainstorm.md` [D] and `05-architecture-best-practice.md` [J] was traced through the gap reports [GC, GA, GI], the surveys [R research, C commercial, A agent skills] and the catalogues [01-A, 01-P, 01-T, 02] to the URL in the originating report's source table. Where the original was cheap to reach it was fetched and read; 24 sources were checked. Status meanings: **confirmed at source** (read in the original), **confirmed in report** (chain holds, original not reachable here), **secondary-or-vendor**, **thin** (real number, population too small or anecdotal for the weight placed on it), **misread** (real number, used for a different population or meaning), **not found**.

## 2. Decisions resting on weak or misread evidence

1. **Complex-units with no tier cap (D 2.2).** Best-of-four-models F1 on three Java smells; nesting, conditionals and parameters unmeasured. Keep the family default-on, keep tier A on the general corroboration rule (D 4.7 already does), and drop "no tool needed" from the reason column.

2. **Verifier expected to reach S24-class precision (J 1, J 4, D 4.7).** The 95.5 percent came from an agent free to explore; D's verifier gets a 30-line window by design. Either accept that the bounded verifier starts nearer the vanilla-prompt result, or let it follow referrers and coupled files on request. Set the bar (item 6) with this in mind.

3. **Hotspot interest term justified by Code Red (J 1, principle 1, D 4.8).** Code Red validates a smell composite with no churn component; J's "high-churn" wording is an error. Churn is supported by S35 and S36; the complexity half assumes indentation tracks Code Health. Reword J 1, add a fixture check that `hotspot_score` correlates with planted debt, and hold `wH` at the balanced default until it exists.

4. **"Self-reported confidence is near-random" (J 4, J 5).** S15 never measured self-reports. Removing `confidence` still stands on S12 and S13 and on the double-counting argument; change the citation and move S15's 33 percent under quote verification only.

5. **Architecture precision quoted as 64 to 82 percent (J 3, J 5, GA TD-07, GC TD-20).** That is agreement with Arcan, whose own output was 63 percent intentional. Keep verifier-mandatory and tier B for reading-only cycles; replace the numbers with "unmeasured against humans".

6. **Release bar 0.80 (D 1, 4.14, 5 Q8, 9 decision 12).** Unsupported by any measurement. Change D 5 Q8 to "a convention pending the first live run" and frame decision 12 as choosing a provisional bar that the first row of `docs/evaluation-log.md` tests.

7. **Chunking thresholds attributed to the judge (D 4.5, 5 Q10).** 200k LOC is a README remark; 1,500 files has no source. Keep both as configurable defaults and remove "the judge's degradation point".

8. **SATD miner justified by accuracy (J 2 stage 2, J 4, GC TD-22).** The evidence says a zero-shot LLM outscores the keyword baseline. The real argument, which D 4.3 implements, is zero-cost blame age, ticket flags and location-keyed corroboration. Reword; no mechanism change. The 0.58 belongs to four tags, not the 62-pattern list D adopts.

9. **Duplication at rank 5 (D 2.1; 02 TD-05).** Importance rests on vendor data while the research survey found most clones benign. D's tier B cap already treats it as low-confidence, so the disposition is safe; re-score 02 to importance 3 with S38 cited, which moves TD-05 below TD-06 and TD-07 without changing dispositions.

10. **Google's null result as support for principle 8 (J 1, principle 8, J 5).** The paraphrase drops the random-forest half and overgeneralises three types to all. Principle 8 stands on S40, S41, S44, S38; cite Jaspan and Green instead for the tier logic and for the three-type scope.

11. **Verifier false-positive prior of 50 to 63 percent (J 4, J 2 stage 7).** One Python project's static-detector output. Affects expectations only; state it as illustration and let `evaluate.py` produce the real number.

12. **Migration rank (D 2.1 TD-06).** Google's rank 1 is explicitly non-generalising and the second figure is a vendor survey. Default-on is defensible on cost; the reason column should carry 02 caveat 10's thin flag.

None of the twelve removes a stage or a family. Items 2, 3 and 6 interact: a bounded-context verifier, an interest term whose complexity half is unvalidated, and a precision bar chosen without measurement are the three things the first live run must settle together.
