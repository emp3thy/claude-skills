# tech-debt-scan Redesign (Waves 1-5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the `tech-debt-scan` skill with git-hotspot ranking, deterministic inventory pre-passes, an infrastructure-debt scout, four real prioritization schema fields, and richer ralph-ready PBI bundles — without breaking the language-agnostic, git-optional, bounded-token invariants.

**Architecture:** Deterministic Python scripts under `skills/tech-debt-scan/scripts/` do all non-LLM work; the LLM only dispatches scouts and picks the top-5. This plan adds fields to the synthesis output contract and cascades them through the five pipeline files (`build_synthesis_prompt.py → design_writer.py → design_parser.py → bundle_writer.py → validation.py`), plus two inventory pre-passes and one git-gated churn pass in `inventory.py`, and a 7th scout category in `categories.py`. Three byte-exact golden fixtures are regenerated as fields land.

**Tech Stack:** Python 3.11+ (uses `datetime.UTC`, PEP 604 `X | None`), `pytest`, `PyYAML` (`yaml.safe_load` only), stdlib `subprocess`/`re`/`math`. No new third-party dependency.

## Global Constraints

- **Language-agnostic** — no per-language AST parser; LLM structural reading plus git/text pre-passes only.
- **Git-optional** — churn/hotspot degrade gracefully when `.git` is absent (skip the signal, never abort).
- **Bounded tokens** — ~60-80k per scan; pre-passes route attention, they must not inflate the prompt.
- **No-improvisation abort** — the SKILL.md exit-5 contract is preserved.
- **Top-5 cap + bounded PBIs** — `TOP5_COUNT=5` and `MAX_FINDINGS=30` are unchanged.
- **NO hours / NO TDR** — size/risk are ordinal (`change_size`, `change_risk`); never a time or dollar estimate.
- **`change_risk` is informational only** — it gates nothing and does not couple to `disposition`.
- **LF-only file IO** — all rendered artefacts are built as `"\n".join(parts)` and written via `write_bytes`; never rely on text-mode. LOC/pre-pass counts iterate the opened file handle, never `Path.read_text()` (avoids Windows CRLF translation).
- **Direct-path invocable** — every script runs as `python scripts/<name>.py` from `skills/tech-debt-scan/`, no `-m`, no package install.
- **Enum values are locked** (must be byte-identical everywhere they appear):
  - `confidence`: integer `1`-`5`
  - `change_size`: one of `S | M | L | XL`
  - `change_risk`: one of `low | med | high`
  - `disposition`: one of `full-repayment | debt-conversion | interest-only`

```python
def _git_churn(root: Path) -> dict[str, int]:
    """Return {relpath: commit-touch count}. Empty dict when git is unavailable.

    Git-optional invariant: a missing .git, a missing git binary, or a git
    error all degrade to an empty map (churn omitted), never an abort.
    """
    if not (root / ".git").exists():
        return {}
    try:
        proc = subprocess.run(
            ["git", "-C", str(root), "log", "--pretty=format:", "--name-only"],
            capture_output=True,
            text=True,
            check=False,
        )
    except (OSError, ValueError):
        return {}
    if proc.returncode != 0:
        return {}
    counts: dict[str, int] = {}
    for line in proc.stdout.splitlines():
        rel = line.strip()
        if rel:
            counts[rel] = counts.get(rel, 0) + 1
    return counts
```

def _finding_churn(finding: dict[str, Any], churn_by_file: dict[str, int]) -> int:
    return max(
        (churn_by_file.get(ev.get("file", ""), 0) for ev in finding.get("evidence", [])),
        default=0,
    )


def build_prompt(
    raw_findings: list[dict[str, Any]],
    churn_by_file: dict[str, int] | None = None,
) -> str:
    """Render the top-5 synthesis prompt from the raw scout findings.

    When ``churn_by_file`` is provided, findings are ranked by the git-hotspot
    key ``severity * log1p(churn)`` with severity as a tiebreak; otherwise by
    severity alone (git-optional fallback). Capped at MAX_FINDINGS.
    """
    if churn_by_file:
        ranked = sorted(
            raw_findings,
            key=lambda f: (
                f.get("severity", 0) * math.log1p(_finding_churn(f, churn_by_file)),
                f.get("severity", 0),
            ),
            reverse=True,
        )
    else:
        ranked = sorted(
            raw_findings,
            key=lambda f: f.get("severity", 0),
            reverse=True,
        )

    truncated_from = 0
    if len(ranked) > MAX_FINDINGS:
        truncated_from = len(ranked)
        ranked = ranked[:MAX_FINDINGS]
        print(
            f"warning: truncated {truncated_from} raw findings to top {MAX_FINDINGS} "
            "by hotspot rank before synthesis",
